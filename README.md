# 加密机会筛选器（Crypto Opportunity Screener）

私人研究辅助 MVP：从 CoinGecko **免费公开 API** 拉取市值 Top ~150 币种，结合趋势榜与简单规则，给出「是否值得继续深挖」的排序与风险标签。

> **免责声明：本工具不是投资建议、不构成任何交易推荐。** 加密资产风险极高，请自行尽职调查。

## 功能

- 市值榜价格 / 市值 / 24h·7d·30d 涨跌 / 成交额 / 成交÷市值
- 透明「研究价值分」与拆解
- 公开催化剂线索（趋势榜 + 静态分类提示）
- 风险筹码（高波动、低流动性、已暴涨、低市值等）中文说明
- 筛选、排序、点击行查看证据与风险详情
- 深色仪表盘；服务端代理 + 内存缓存约 60 秒，避免浏览器 CORS 并温和限速

## 技术栈

Vite + React + TypeScript + Tailwind CSS v4  
API 代理：Vite 插件中间件（`dev` 与 `preview` 均可用）

## 运行

```bash

npm run dev      # http://127.0.0.1:5173

npm run build && npm run preview   # http://127.0.0.1:4173
```

## 研究价值分公式

```
score = clamp(0–100,
  7d动能(0–28) + 24h动能(0–18) + 成交关注(0–20)
  + 催化剂(0–18) + 市值区间(0–16) + 风险惩罚
)
```

| 分量 | 说明 |
|------|------|
| 7d / 24h 动能 | `tanh` 软压缩涨跌幅，温和上涨得分更高 |
| 成交关注 | `min(成交额/市值 × 400, 20)` |
| 催化剂 | 趋势榜 +12；分类线索最多 +6 |
| 市值甜区 | 约 $80M–$8B 较高分 |
| 惩罚 | 7 日暴涨、低流动性、微盘、极端 24h 波动 |

UI 内可展开同一说明。分数只用于研究排序，**不是收益预测**。

## 数据与限速

- `GET /api/screener`：合并 markets page1+2 + `/search/trending`
- 上游请求间隔约 ≥1.2s；响应内存缓存约 60s（429 时短缓存）
